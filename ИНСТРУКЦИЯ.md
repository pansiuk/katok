# «Каток Минск» — публикация в Google Play: пошаговая инструкция

Что в этом проекте:

```
katok/
├── app/                        ← само приложение (PWA)
│   ├── index.html              ← весь интерфейс
│   ├── manifest.webmanifest    ← паспорт приложения (имя, иконки, цвета)
│   ├── sw.js                   ← офлайн-режим
│   ├── schedule.json           ← расписание (обновляется роботом)
│   ├── privacy.html            ← политика конфиденциальности (нужна для Play)
│   └── icons/                  ← иконки приложения
├── parser/                     ← робот-парсер сайтов арен
│   ├── parse.js
│   └── package.json
├── .github/workflows/
│   └── update-schedule.yml     ← ежедневный автозапуск парсера (8:10 по Минску)
├── ПОЛИТИКА_ДАННЫХ.md          ← источники и правовая основа использования данных
└── ИНСТРУКЦИЯ.md               ← этот файл
```

Как это работает после настройки: расписание обновляется **само, в облаке GitHub, каждое утро** — твой компьютер и телефон не участвуют. Приложение в Play обновлять не нужно: оно скачивает свежий `schedule.json` при каждом открытии.

---

## Этап 1. GitHub (бесплатно, ~20 минут)

1. Зарегистрируйся на https://github.com (кнопка Sign up, нужна только почта).
2. Создай репозиторий: кнопка **New repository** → имя `katok` → Public → Create.
3. Загрузи файлы проекта: в репозитории **Add file → Upload files** → перетащи ВСЁ содержимое этой папки (включая скрытую папку `.github` — если через браузер она не грузится, создай файл через **Add file → Create new file**, в имени набери `.github/workflows/update-schedule.yml` и вставь содержимое). → Commit.
4. Включи хостинг: **Settings → Pages** → Source: «Deploy from a branch» → Branch: `main`, папка `/ (root)` → Save.
   Через пару минут сайт оживёт по адресу `https://ТВОЙ_ЛОГИН.github.io/katok/app/`.
5. Разреши роботу писать в репозиторий: **Settings → Actions → General** → внизу «Workflow permissions» → выбери **Read and write permissions** → Save.
6. Проверь робота: вкладка **Actions** → «Обновление расписания» → **Run workflow**. Через 2–3 минуты должна появиться зелёная галочка, а `app/schedule.json` — обновиться. Дальше он будет запускаться сам каждое утро.

Проверка: открой `https://ТВОЙ_ЛОГИН.github.io/katok/app/` на телефоне — приложение должно работать, а Chrome предложит «Добавить на главный экран».

## Этап 2. Сборка Android-пакета (без программирования, ~15 минут)

Используем бесплатный сервис PWABuilder от Microsoft:

1. Открой https://www.pwabuilder.com
2. Вставь адрес приложения: `https://ТВОЙ_ЛОГИН.github.io/katok/app/` → Start.
3. Сервис проверит манифест и service worker (обе галочки должны быть зелёными) → **Package for stores** → **Android**.
4. В настройках пакета:
   - Package ID: `io.github.ТВОЙ_ЛОГИН.katok` (латиницей, без дефисов)
   - App name: `Каток Минск`
   - Остальное можно оставить по умолчанию → **Download**.
5. В архиве будут: `*.aab` (то, что загружается в Play), `*.apk` (для проверки на своём телефоне), `signing.keystore` и `assetlinks.json`.
   ⚠️ **Сохрани `signing.keystore` и пароли из архива в надёжном месте** — без них нельзя будет выпускать обновления.
6. Файл `assetlinks.json` загрузи в репозиторий по пути `app/.well-known/assetlinks.json` (Add file → Create new file, имя `app/.well-known/assetlinks.json`). Это убирает адресную строку браузера в приложении.

## Этап 3. Google Play Console (~$25, проверка 1–7 дней)

1. Зарегистрируй аккаунт разработчика: https://play.google.com/console/signup — разовый взнос $25 банковской картой. Понадобится подтверждение личности (документ). Учти: с картами белорусских банков оплата может не пройти — может выручить карта иностранного банка.
2. **Create app**: название «Каток Минск», язык — русский, тип — App, Free.
3. Заполни обязательные разделы (Dashboard подсвечивает их списком):
   - **Privacy policy**: укажи `https://ТВОЙ_ЛОГИН.github.io/katok/app/privacy.html`
   - **Data safety**: приложение не собирает данные (во всех вопросах «No»).
   - **Content rating**: заполни анкету (без насилия/азарта → рейтинг 3+).
   - **Target audience**: 13+ (не детское приложение).
   - **Store listing**: краткое описание, полное описание, иконка 512×512 (`app/icons/icon-512.png`), баннер 1024×500 и минимум 2 скриншота телефона (сделай скриншоты приложения с телефона).
4. **Production → Create new release** → загрузи `.aab` из этапа 2 → заполни «Release notes» → Review → Rollout.
5. Жди проверку Google (обычно 1–7 дней для нового аккаунта). После одобрения приложение появится в Play Market.

## Обновления в будущем

- **Расписание** — само, каждый день, ничего делать не нужно.
- **Дизайн/функции** — правишь файлы в `app/` в репозитории (можно прямо в браузере GitHub), сайт обновится сам. Пакет в Play перевыпускать НЕ нужно: TWA показывает живой сайт.
- Перевыпуск `.aab` нужен только если сменишь адрес сайта, имя или иконку приложения.

## Важные оговорки

- Название «КатОК» принадлежит автору оригинального приложения — поэтому используем «Каток Минск». Не используй чужой логотип и скриншоты.
- Приложение неофициальное: расписание собирается с открытых сайтов арен, возможны изменения и ошибки — дисклеймер уже встроен в интерфейс.
- Использование данных со сторонних сайтов задокументировано в файле `ПОЛИТИКА_ДАННЫХ.md` (источники, правовая основа, режим вежливого парсинга, контакт для претензий). Держи его в репозитории — на него удобно ссылаться при вопросах модерации Play или арен. Эта же информация показана пользователям во вкладке «Инфо» приложения.
- Первые запуски парсера стоит проконтролировать во вкладке Actions: сайты арен иногда меняют вёрстку, и парсер может потребовать правок (это можно поручить Claude — просто вернись с логом ошибки).
